# Smart Student Sri Lanka: future feature ideas

These are **ideas only**. None of them is built unless it also appears as "Available" on the in-app About page. Ideas are not promises: each one needs a check for curriculum accuracy, copyright, student privacy and cost before it is built. Anything involving an external service, API key, internet connection or paid plan is called out in `ROADMAP.md`. Student-facing features never include public chat, public profiles or public rankings.
