# ஸ்மார்ட் ஸ்டூடன்ட் இலங்கை: Supabase அமைப்பு வழிகாட்டி (தொடக்கநிலையாளர்களுக்கு)

> குறிப்பு: இந்த வழிகாட்டி AI-யால் எழுதப்பட்டது. தமிழ் நன்கு அறிந்த ஒருவர் வாசித்துச் சரிபார்ப்பது நல்லது. Supabase இணையதளத்தில் உள்ள பட்டியல் (menu) பெயர்கள் காலத்துக்குக் காலம் மாறலாம்; பெயர் சற்று வேறுபட்டால் அதே பொருள் தரும் பட்டியலைத் தேடுங்கள்.

## முதலில் ஒரு முக்கியமான விஷயம்: இரண்டு வகைச் சாவிகள் (keys)

| சாவி | எங்கே பயன்படுத்தலாம்? |
|---|---|
| **anon public key** (பொதுச் சாவி) | இணையதளத்தில் பயன்படுத்தலாம். பாதுகாப்பு விதிகள் (RLS) இதைப் பாதுகாக்கின்றன. |
| **service_role key** (இரகசியச் சாவி) | **ஒருபோதும்** இணையதளக் குறியீட்டிலோ, படங்களிலோ, நண்பர்களுக்கு அனுப்பும் செய்திகளிலோ வைக்கக் கூடாது. இது எல்லாப் பாதுகாப்பையும் தாண்டும் சாவி. |

## படி 1: Supabase திட்டம் (project) உருவாக்குங்கள்

1. supabase.com திறந்து, கணக்கு உருவாக்கி உள்நுழையுங்கள்.
2. **New project** அழுத்துங்கள். பெயர் கொடுங்கள் (எ.கா. smart-student-lk).
3. **Database password** ஒன்றைத் தேர்ந்தெடுத்து, பாதுகாப்பான இடத்தில் எழுதி வையுங்கள்.
4. மாணவர்களுக்கு அருகிலுள்ள பிராந்தியத்தைத் (region) தேர்ந்தெடுங்கள் (எ.கா. Singapore அல்லது Mumbai).
5. திட்டம் தயாராகும் வரை சில நிமிடங்கள் காத்திருங்கள்.

(Bolt-இல் ஏற்கனவே Supabase இணைக்கப்பட்டிருந்தால், புதிய திட்டம் தேவையில்லை; அந்தத் திட்டத்தையே பயன்படுத்துங்கள்.)

## படி 2: இணையதளத்துக்கான இரண்டு பொது மதிப்புகளை எடுங்கள்

1. இடப்பக்கத்தில் **Project Settings** → **API** (அல்லது **API Keys**) பகுதிக்குச் செல்லுங்கள்.
2. **Project URL** என்பதை நகலெடுங்கள் → இது `VITE_SUPABASE_URL`.
3. **anon public** சாவியை நகலெடுங்கள் → இது `VITE_SUPABASE_ANON_KEY`.
4. திட்டக் கோப்புறையில் `.env` என்ற கோப்பை உருவாக்கி (`.env.example` ஐ நகலெடுத்து) இந்த இரண்டையும் நிரப்புங்கள்.
5. **service_role** சாவியை இங்கே வைக்க வேண்டாம்.

## படி 3: தரவுத்தளத்தை (database) அமையுங்கள்

1. இடப்பக்கத்தில் **SQL Editor** → **New query** அழுத்துங்கள்.
2. கீழ்க்காணும் நான்கு கோப்புகளையும் **இதே வரிசையில்** ஒவ்வொன்றாகத் திறந்து, உள்ளடக்கம் முழுவதையும் நகலெடுத்து SQL Editor-இல் ஒட்டி, **Run** அழுத்துங்கள்:
   1. `supabase/migrations/20260101000001_schema.sql`
   2. `supabase/migrations/20260101000002_rls.sql`
   3. `supabase/migrations/20260101000003_storage.sql`
   4. `supabase/migrations/20260101000004_seed_subjects.sql`
3. ஒவ்வொன்றுக்குப் பின்னும் "Success" என்று வர வேண்டும். பிழை வந்தால், அந்தச் செய்தியை எழுதி வைத்துக்கொண்டு அடுத்த கோப்பை இயக்காமல் உதவி கேளுங்கள்.
4. **Table Editor** சென்று `subjects` என்ற அட்டவணையில் தமிழ், கணிதம், விஞ்ஞானம் முதலிய பாடங்கள் இருப்பதைப் பாருங்கள்.
5. **Storage** சென்று `resources` என்ற தொகுதி (bucket) இருப்பதையும், அது **Private** (தனிப்பட்டது) என்பதையும் உறுதிசெய்யுங்கள்.

## படி 4: உள்நுழைவு (Authentication) அமைப்புகள்

1. **Authentication** பகுதியில், மின்னஞ்சல் உறுதிப்படுத்தல் (**Confirm email**) இயக்கத்தில் இருக்கட்டும்.
2. கடவுச்சொல்லின் குறைந்தபட்ச நீளத்தை (**Minimum password length**) 8 ஆக வையுங்கள்.
3. **URL Configuration** பகுதியில்:
   - **Site URL**: உங்கள் இணையதள முகவரி (எ.கா. `https://smart-student.example.lk`).
   - **Redirect URLs**: `https://உங்கள்-முகவரி/reset-password` என்பதைச் சேர்யுங்கள்.
4. உங்கள் சொந்த மின்னஞ்சல் சேவையை (SMTP) பின்னர் அமையுங்கள்; Supabase-இன் இயல்புநிலை சேவைக்கு அனுப்பும் எண்ணிக்கை வரம்பு உண்டு.

## படி 5: Edge Functions (சேவையகப் பக்கச் செயல்பாடுகள்)

இரண்டு செயல்பாடுகள் உள்ளன: `setup-admin` (முதல் நிர்வாகியை உருவாக்க) மற்றும் `delete-account` (மாணவர் தன் கணக்கை நீக்க).

1. Supabase CLI நிறுவியிருந்தால் (கணினியில்):
   ```
   supabase login
   supabase link --project-ref உங்கள்-project-ref
   supabase functions deploy setup-admin
   supabase functions deploy delete-account
   ```
2. Bolt-இல் இருந்தால், `supabase/functions` கோப்புறையில் உள்ள இரண்டு செயல்பாடுகளையும் deploy செய்யச் சொல்லுங்கள்.
3. இரகசிய மதிப்புகளை (secrets) அமையுங்கள். **Edge Functions → Secrets** பகுதியில் (அல்லது CLI-இல்):
   - `INITIAL_ADMIN_EMAIL` = நிர்வாகியின் மின்னஞ்சல்
   - `INITIAL_ADMIN_PASSWORD` = தற்காலிகக் கடவுச்சொல்
   - `SETUP_TOKEN` = நீங்கள் மட்டும் அறிந்த நீண்ட சீரற்ற எழுத்துத் தொடர் (எ.கா. 30 எழுத்துகள்)

> **எச்சரிக்கை: "1010" பற்றி.** தற்காலிகக் கடவுச்சொல்லாக 1010 கேட்டிருந்தீர்கள். இது குறியீட்டிலோ தரவுத்தளத்திலோ எங்கும் எழுதப்படவில்லை; இரகசிய மதிப்பாக மட்டுமே இருக்கும். ஆனால்:
> - இது 4 எழுத்துகள் மட்டுமே. Supabase குறைந்தபட்ச நீளத்தை (இயல்பாக 6) கேட்பதால் அது ஏற்க மறுக்கலாம். அப்படி நடந்தால் நீளமான தற்காலிக மதிப்பைப் பயன்படுத்துங்கள்.
> - மாற்றும் வரை, நிர்வாகியின் மின்னஞ்சலையும் இந்தக் கடவுச்சொல்லையும் அறிந்த எவரும் உள்நுழைந்து, கடவுச்சொல்லை மாற்றி, நிர்வாகி ஆகிவிடலாம். 4 இலக்க எண்ணை நிமிடங்களில் ஊகிக்கலாம். எனவே **நீளமான, ஊகிக்க முடியாத தற்காலிக மதிப்பை** வைத்து, அமைத்த உடனே மாற்றுவது பாதுகாப்பானது.

## படி 6: முதல் நிர்வாகியை உருவாக்குங்கள் (ஒரே ஒரு முறை)

1. உலாவியில் `https://உங்கள்-இணையதளம்/setup` திறக்கவும்.
2. `SETUP_TOKEN` ஐ உள்ளிட்டு **Create administrator** அழுத்துங்கள்.
3. "Administrator created" என்று வந்தால் வெற்றி. "Setup has already been completed" என்று வந்தால் மீண்டும் செய்ய முடியாது (இது வேண்டுமென்றே செய்யப்பட்ட பாதுகாப்பு).
4. `/signin` சென்று நிர்வாகி மின்னஞ்சலுடனும் தற்காலிகக் கடவுச்சொல்லுடனும் உள்நுழையுங்கள்.
5. புதிய கடவுச்சொல் கேட்கும் பக்கம் தானாகவே வரும். குறைந்தது 12 எழுத்துகள் உள்ள, தற்காலிகத்தை விட வேறுபட்ட புதிய கடவுச்சொல்லை வையுங்கள். இதைச் செய்யும் வரை நிர்வாக அதிகாரம் இயங்காது.
6. பின்னர் மூன்று இரகசிய மதிப்புகளையும் நீக்குங்கள் (**Secrets** பகுதியில் delete, அல்லது `supabase secrets unset INITIAL_ADMIN_EMAIL INITIAL_ADMIN_PASSWORD SETUP_TOKEN`).

## படி 7: உள்ளடக்கத்தைச் சேர்த்தல்

1. உள்நுழைந்து மேலே **Admin** அழுத்துங்கள்.
2. **Subjects**: "Other subject" (★) என்பதற்குப் பெயர் முடிவானதும் மாற்றுங்கள். **Grades** மூலம் எந்தப் பாடம் எந்தத் தரத்துக்கு உரியது என்பதைச் சேருங்கள்.
3. **PDFs** → **Upload PDF**: PDF கோப்பு (50 MB வரை), தலைப்பு, பாடம், தரம், மொழி, மூலம் (source) ஆகியவற்றை நிரப்புங்கள். **சரிபார்ப்பு நிலை** (Verification): சரிபார்க்காதவற்றை "Needs verification" அல்லது "Sample" என்றே வையுங்கள். பதிப்புரிமை வைத்திருப்பவர் அனுமதித்தால் மட்டுமே download / print ஐத் தேர்ந்தெடுங்கள்.
4. பின்னர் **Publish** அழுத்துங்கள். வெளியிடாதவை மாணவர்களுக்குத் தெரியாது.
5. **Reports** பகுதியில் மாணவர்களின் புகார்களையும் கோரிக்கைகளையும் பாருங்கள்.

## சிக்கல் வந்தால்

- "Supabase is not connected yet" என்று திரையில் வந்தால்: `.env` இல் இரண்டு மதிப்புகளையும் சரிபார்த்து, இணையதளத்தை மீண்டும் தொடங்குங்கள்.
- PDF திறக்கவில்லை என்றால்: அது **Publish** செய்யப்பட்டுள்ளதா என்று பாருங்கள்; Storage-இல் கோப்பு உள்ளதா என்றும் பாருங்கள்.
- கடவுச்சொல் மீட்டமைப்பு இணைப்பு வேலை செய்யவில்லை என்றால்: படி 4-இல் உள்ள Redirect URL சரியா என்று பாருங்கள்.
